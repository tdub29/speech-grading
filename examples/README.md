# Examples

These examples use synthetic speech. They show the input, rendered feedback,
structured report, and optional word-choice enrichment packet.

From the repository root, after installing the package:

```bash
orator examples/sample_talk.txt --html report.html --json report.json
```

Open [sample_report.html](sample_report.html) for a checked-in report, or inspect
[sample_report.json](sample_report.json) for its structured representation.
Generated local reports and the grading ledger are excluded from version control.
