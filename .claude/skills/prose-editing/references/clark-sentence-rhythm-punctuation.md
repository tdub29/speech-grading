
# Roy Peter Clark: Sentence Rhythm and Punctuation Pass

## When to use

Use when the user says a draft sounds flat, awkward, choppy, rushed, or hard to read aloud.

Don't trigger for broad prose improvement when another skill owns the artifact. This skill should end in the concrete output named below.

## The framework

- Clark treats sentence length as meaning: short sentences deliver punch, long sentences carry movement and accumulation.
- Punctuation is not decoration; it tells readers when to pause, accelerate, connect, or absorb a turn.
- Variation works only when it serves emphasis. Random variety is noise.

## How to apply

1. Create a sentence-length map by word count and mark repeated lengths or shapes.
2. Identify the sentence that deserves to be shortest. Move the key point there or trim it to force.
3. Identify one place where a longer sentence can legitimately gather related detail instead of chopping it into fragments.
4. Audit punctuation marks for function: comma links, semicolon balances, colon promises, dash interrupts, period lands.
5. Read the passage aloud and mark breath failures or false stops.
6. Rewrite with intentional alternation: setup, development, turn, landing.

## Common failure modes

- Breaking every long sentence into short ones and losing complexity.
- Using semicolons or dashes to sound literary rather than to clarify relation.
- Mistaking sentence fragments for punch when the idea lacks weight.
- Creating rhythmic variety that undermines logical order.
- Letting punctuation hide a structural problem that needs a rewrite.
- Ignoring paragraph-level rhythm; sentence music changes across the paragraph, not just inside one line.

## Output artifact

Produce: sentence-length map, punctuation function audit, read-aloud flags, and a revised passage with notes on rhythm choices.

Use this compact structure:

```markdown

### Diagnosis
[What is failing and why]

### Revision Plan
[Concrete edits/checks in priority order]

[Before/after or revised passage]

[Failure modes most relevant here]
```
