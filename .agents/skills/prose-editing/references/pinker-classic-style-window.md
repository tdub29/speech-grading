
# Steven Pinker: Classic Style Window

## When to use

Use when a draft explains something but sounds like it is talking about the act of explaining rather than showing the thing itself.

Don't trigger for broad prose improvement when another skill owns the artifact. This skill should end in the concrete output named below.

## The framework

- Classic style's guiding metaphor is joint attention: the writer has seen something and directs the reader's gaze to it.
- The writer and reader are equals in a simulated conversation; the writer knows something worth showing but does not posture.
- Classic style hides the labor of composition without hiding evidence or uncertainty that matters.

## How to apply

1. Identify self-conscious scaffolding: 'this essay will discuss,' 'it is worth noting,' 'the purpose of this section.'
2. Find the object, action, relationship, or idea the reader is supposed to see.
3. Rewrite sentences so the thing appears directly, through concrete nouns, active relations, and clean explanation.
4. Remove status displays, defensive hedges, and process narration unless they help truthfulness.
5. Check humility: confidence in showing is not arrogance about certainty.
6. Return a before/after that makes the same idea visible rather than announced.

## Common failure modes

- Confusing classic style with oversimplification; hard ideas can be shown clearly.
- Erasing uncertainty that readers need to know.
- Replacing all signposts even when a long technical passage needs orientation.
- Sounding breezy about a serious topic.
- Trying to imitate Pinker's voice instead of applying the stance.
- Using vivid metaphors that draw attention away from the actual idea.

## Output artifact

Produce: stance diagnosis, self-consciousness cuts, visible-object rewrite, and a note on what uncertainty/signposting remains for honesty.

Use this compact structure:

```markdown
## Classic Style Window

### Diagnosis
[What is failing and why]

### Revision Plan
[Concrete edits/checks in priority order]

### Rewrite
[Before/after or revised passage]

### Watchouts
[Failure modes most relevant here]
```
