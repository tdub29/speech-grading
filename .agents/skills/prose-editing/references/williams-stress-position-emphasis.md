
# Williams & Bizup: Stress-Position Emphasis

## When to use

Use when the user asks to make the point land, improve emphasis, fix buried takeaways, or make a paragraph's ending stronger.

Don't trigger for broad prose improvement when another skill owns the artifact. This skill should end in the concrete output named below.

## The framework

- Readers give special weight to sentence endings and other closure points. Williams calls this the stress position.
- Clarity gets readers through a sentence; emphasis tells them what to remember.
- The right stress position usually holds new, complex, surprising, or consequential information, not routine setup.

## How to apply

1. Identify the intended takeaway of each sentence or paragraph in plain words.
2. Mark what currently occupies each stress position: sentence end, paragraph end, section end.
3. If setup or low-value detail occupies the stress position, move it earlier.
4. Move the key term, contrast, consequence, or number into the stress position.
5. Use end-weight carefully: put long/complex units late only if readers have enough context to process them.
6. Check the chain of endings across the paragraph: do they build toward the intended point?

## Common failure modes

- Burying the important word between commas because it appeared chronologically there in the source notes.
- Ending with weak metadiscourse: 'as discussed above,' 'in this regard,' 'going forward.'
- Putting every sentence's heaviest phrase at the end and creating predictable thuds.
- Moving new information late without giving old information first.
- Confusing dramatic emphasis with logical emphasis.
- Fixing sentence endings while leaving paragraph or section endings flat.

## Output artifact

Produce: intended emphasis statement, current stress-position map, rewritten sentence set, and paragraph ending recommendation.

Use this compact structure:

```markdown
## Stress-Position Emphasis

### Diagnosis
[What is failing and why]

### Revision Plan
[Concrete edits/checks in priority order]

### Rewrite
[Before/after or revised passage]

### Watchouts
[Failure modes most relevant here]
```
